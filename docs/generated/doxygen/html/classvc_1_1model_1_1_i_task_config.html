Detailed Description

Abstract per-task-type configuration: defines the JSON (de)serialization and cloning contract that every concrete ITaskConfig subclass (one per TaskType) must implement. Not a QObject; concrete subclasses expose their own QMetaObject via getMetaObject() for property introspection.
