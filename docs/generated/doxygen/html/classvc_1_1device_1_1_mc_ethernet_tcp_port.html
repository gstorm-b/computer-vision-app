Detailed Description

McMsgInterface transport that talks to the PLC over a plain TCP/IP socket (QTcpSocket), driven synchronously via waitFor*() calls.

◆ ReceiveMsg()

const MsgErrorState vc::device::McEthernetTcpPort::ReceiveMsg ( QByteArray & buffer,
int wait_buffer = 1 )
inlineoverridevirtual

Waits up to wait_buffer ms for readyRead, then appends any available bytes to buffer. Accumulates elapsed wait time across calls (m_total_wait_time) so repeated BufferEmpty results eventually surface as ResponseTimeout once m_config.m_responseTimeout is exceeded.

Returns
NoError if bytes were appended (resets the accumulated wait time), BufferEmpty while still under the response timeout, ResponseTimeout once it is exceeded
