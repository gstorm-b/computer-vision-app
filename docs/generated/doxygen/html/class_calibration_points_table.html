Detailed Description

6-column table used by camera calibration UI:

| Img X (px) | Img Y (px) | World X (mm) | World Y (mm) | World Z (mm)

Each row holds one 2D image -> 3D world correspondence pair. Image columns are populated by the board detector and are read-only. World columns are user-editable (or filled programmatically from a robot teach pendant via setWorldPointsFromRobot()).

Emits pointsEdited() when any user edit lands in a world column. Programmatic fills (setImagePoints / setWorldPoints*) are guarded by a signal blocker and do not emit.
