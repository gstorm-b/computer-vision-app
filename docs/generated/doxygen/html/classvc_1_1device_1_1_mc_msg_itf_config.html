Detailed Description

Abstract base for a message-interface (transport) configuration: the common connect/write/response timeout Q_GADGET properties shared by every McMsgInterface transport, plus the JSON (de)serialization and meta-object hooks each transport-specific subclass (e.g. McMsgEthernetTcpCfg) must implement.
