Detailed Description

Modal table editor for vc::model::GripperPresetStore: add, edit and remove named gripper geometries.

Edits a working copy. The caller reads presets() only after exec() returns Accepted; cancelling discards everything. Name uniqueness is validated on commit and reported in the dialog rather than through a message box, so a rejected edit does not interrupt the user's flow.

Note
Parent this to the widget whose QSS should style it — it has no per-form sheet of its own and inherits the parent's, which is what keeps it theme-correct.
