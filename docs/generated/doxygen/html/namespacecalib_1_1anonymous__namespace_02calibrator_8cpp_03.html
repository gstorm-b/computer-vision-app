bool calib::anonymous_namespace{calibrator.cpp}::fitPlane ( const std::vector< cv::Point3f > & pts,
cv::Vec4d & plane )

Fits a plane ax + by + cz + d = 0 through pts by SVD on the centred coordinates, then normalizes the normal and flips its sign so c >= 0 (keeps a non-vertical work plane's normal pointing toward +Z).

Parameters
ptsrobot-space points to fit; need at least 3
planeoutput plane coefficients (a, b, c, d) with a^2+b^2+c^2 = 1
Returns
false if pts.size() < 3, the SVD result is degenerate (fewer than 3 rows in vt), or the resulting normal is ~zero length
