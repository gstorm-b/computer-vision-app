Detailed Description

Concrete mtc::IRobotPickingChecker: the single bridge that pulls together the three families the pure-vision matcher must not know about: the calib module (image -> world), the RobotKinematics component (solveAll IK + simplified-mesh collision), and the vc::device robot-check config (preset, TCP, collision toggle).

Built by the layer that owns both the calibration and the robot config (the localization runtime), then injected into an ImageMatcher via setRobotPickingChecker(). The matcher only sees the mtc::IRobotPickingChecker interface, so it stays free of RobotKinematics / calib / vc dependencies.
