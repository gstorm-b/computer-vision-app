Detailed Description

Localization ITask implementation. Binds a PLC, one or more cameras, and a vision output device; drives a LocalizationRuntimeController through commissioning and runtime cycles on a per-device runner model; and persists its pattern library (via PatternGroupManager) and config (TaskLocalizeConfig) to/from JSON.
