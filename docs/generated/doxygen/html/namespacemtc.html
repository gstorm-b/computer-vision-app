Detailed Description

Vision/matching module: MatchBlock/BlockMax implementation (see utils_block_max.h).

Vision/matching module: EdgeMatchConfig, the tunable parameters for gradient-direction edge template matching used by ImageMatcher.

Vision/matching module: template-matching engine (ImageMatcher), pattern group/config model, and the geometry/SIMD helpers it depends on.

Vision/matching module: the ImageMatcher template-matching engine and its MatchResult output type.

Vision/matching module: IMatchTypeConfig, the abstract base for per-algorithm runtime/learn parameter configs.

Vision/matching module: ManagerResult, a lightweight ok/error result type returned by pattern/group manager mutation operations.

Vision/matching module: MatchBoxGripper, the picking/collision-box geometry for a gripper.

Vision/matching module: MatchGroupConfig and MatchGroup implementation (see match_group.h).

Vision/matching module: MatchGroupConfig and MatchGroup, the per-group pattern container and its shared algorithm config.

Vision/matching module: MatchedObject, the per-match result geometry and picking/collision state produced by ImageMatcher.

Vision/matching module: MatchParams, the per-candidate result data produced during pattern search.

Vision/matching module: MatchPattern, a single learned template plus its per-pattern configuration and learned pyramid/edge data.

Vision/matching module: MatchPatternConfig, the per-pattern identity, search-parameter, and picking/collision-box configuration owned by MatchPattern.

Vision/matching module: PatternPoint and PatternLayer, the learned per-point edge data and template layer produced when training a pattern.

Vision/matching module: MatchingType, the algorithm-family discriminator shared by pattern/group configuration.

Machine-vision pattern-matching model: match groups/patterns (MatchGroup, MatchPattern) and their owning manager (PatternGroupManager).

Vision/matching module: IRobotPickingChecker, the dependency-inversion port used by ImageMatcher to query robot reachability/collision without depending on the robot-kinematics/calibration/device layers.

Vision/matching module: MatchBlock/BlockMax, a block-partitioned max-value search helper used to enumerate multiple local maxima in a score/response map.

Match-configuration property browser adapter: binds MatchGroupConfig (and its per-algorithm sub-configs, e.g. EdgeMatchConfig) to a QtVariantPropertyManager-backed property tree.

Property-browser adapters for editing matching configuration (group/algorithm parameters, pattern trees) via QtVariantPropertyManager/Browser.

AVX2 dot-product-of-normalized-gradients score over length edge points: for each point, (Sx*Tx + Sy*Ty) / max(SMag*TMag, eps), summed. Processes 8-wide float blocks with FMA and falls back to a scalar loop for the tail.

Parameters

iSysource gradient Y component per point (32-byte aligned buffer)
iTxtemplate gradient X component per point (32-byte aligned buffer)
iTytemplate gradient Y component per point (32-byte aligned buffer)
SMagsource gradient magnitude per point (32-byte aligned buffer)
TMagtemplate gradient magnitude per point (32-byte aligned buffer)
lengthnumber of edge points to accumulate over
Returns
summed normalized-gradient dot product over all length points
