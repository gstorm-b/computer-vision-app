Detailed Description

MatchGroupConfig — per-group configuration.

Holds group identity and the algorithm-specific config (typeConfig, default EdgeMatchConfig) that is SHARED by every pattern in the group. Typed access helpers (edgeConfig / configAs<T>) return nullptr when the current matching type does not match.

Picking / collision-box geometry is per-pattern — it lives on MatchPatternConfig, not here (collision is an Edge-Based, per-pattern concern).

Copy semantics: deep-copies typeConfig via clone() so each group owns an independent copy of its algorithm config.
