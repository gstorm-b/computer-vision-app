Detailed Description

Adapter that holds per-pattern ROI overlays for the UI session, keyed by group/pattern number. mtc::MatchPatternConfig currently has no dedicated ROI field, so ROIs are kept in-memory only (config is accepted for future use but otherwise unused) and are lost when the session ends.
