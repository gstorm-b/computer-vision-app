Detailed Description

Pattern UI theme tokens (Hybrid Graphite Vision + Orange palette): hex color constants and reusable QSS-fragment builders for C++ painted / inline-styled surfaces in the pattern manager and device wizards that cannot be styled via the QSS files under resrc/styles/*.qss.
