Detailed Description

Model classes for projects, tasks, and task configuration.

Core domain-model namespace: Project, ITask, and their JSON (de)serialization support.

Application data-model types: tasks, device bindings, and localization signal mapping.

Per-camera workspace ROI model types: CameraWorkspace (working + condition crop regions) and CameraWorkspaceMap, its camera-id-keyed container with JSON (de)serialization and reference-image BLOB helpers.

Model-layer task types (ITask and its derivatives): phase/state-machine transitions, assigned-device resolution, and per-device runner synchronization.

LocalizationPipeline member definitions: builds a matcher's pattern model from a MatchGroup and runs workspace-aware ImageMatcher matching for the runtime and commission paths.

Localization matching pipeline: LocalizationPipeline, which loads a MatchGroup's learned model into an ImageMatcher and drives runtime/commission matching runs.

Connection-recovery policy model for localization-owned devices (camera, PLC, vision output): retry/escalate decision rules and default per-role policies.

Task-localization runtime: binds the camera/primary-PLC/vision-output device roles, drives the grab -> match -> send cycle state machine per execute trigger, and applies per-role connection-recovery policies (retry/escalate) on connection loss.

Persistence-layer namespace: Project and ProjectRepository (SQLite-backed load/save of a Project, including its device/task JSON and per-task image blobs).

Namespace for the picking application's project domain model: task type/state enums and their Qt meta-object (Q_ENUM_NS) reflection helpers.

Task model layer: TaskLocalization, the localization ITask implementation that owns the pattern library, runtime controller, and matching worker thread.

Task model layer: per-task configuration types (e.g. TaskLocalizeConfig), state machines, and device/camera bindings for the picking application.

Task model layer: per-task configuration types, state machines, and device/camera bindings for the picking application.
