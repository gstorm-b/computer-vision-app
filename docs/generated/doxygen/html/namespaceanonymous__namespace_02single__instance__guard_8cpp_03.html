int anonymous_namespace{single_instance_guard.cpp}::kNotifyTimeoutMs = 500
constexpr

How long the losing process waits for the running one to connect/acknowledge, in ms. Short on purpose: this runs while the user is staring at a double-clicked icon, and a running instance that cannot answer within a moment is better reported than waited on.
