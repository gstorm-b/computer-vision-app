Detailed Description

QFrame subclass that paints a colored header bar with a title across the top of the widget and hosts a QVBoxLayout (offset below the header) for child widgets added via addWidget().

Constructs the frame with default header styling (dark gray background, bold 10pt "Segoe UI" title font, "Header" title), disables the frame border, and creates the QVBoxLayout used by addWidget(), reserving 30px at the top for the header bar.
