Detailed Description

template<typename Config>
struct PropSpec< Config >

One row in a property spec table. Fields: key — unique internal id (ASCII, used as map key) label — user-visible name in the property browser description — shown in the description panel; nullptr → no tooltip propType — QMetaType type id: QMetaType::Double, Int, Bool, QString … min/max/step — range and step attributes (invalid QVariant = skip) decimals — precision for Double; -1 = use manager default readOnly — disables the editor widget for this property read — extract the value from the config as a QVariant write — apply a changed QVariant value back to the config
