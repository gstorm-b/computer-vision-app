Detailed Description

Modal dialog that lets the user pick a save path (.vtask file) and name for a new task; the values are read back via getPath()/getName() once the dialog is accepted.

Opens a save-file dialog defaulting to "<appDir>/untitled.vtask"; if a path is chosen, stores it, displays it in the save-path field, and focuses the finish button.
