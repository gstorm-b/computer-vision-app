QString vc::device::VisionOutputPosition::toString ( ) const
inline

Formats this position as the wire-format "x,y,z,r" field group.

Returns
"%1,%2,%3,%4" with each axis fixed-width, zero-padded to 8 chars with 2 decimals (e.g. 1.0 -> "00001.00"); the downstream robot parser relies on this exact field format.
