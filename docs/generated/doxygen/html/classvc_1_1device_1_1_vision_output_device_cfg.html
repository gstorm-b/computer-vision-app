Detailed Description

Abstract config for the vision-output device family. Carries only the family-level dispatch field (visionOutputType()) and the shared kinematic-check config; concrete configs (VisionTcpipDeviceCfg, future VisionSerialDeviceCfg, …) inherit and add their transport-specific Q_PROPERTYs.
