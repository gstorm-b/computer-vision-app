Detailed Description

Learned template data for one trained pattern image: the extracted edge points/contours plus the raw SIMD-aligned gradient buffers (pGx/pGy/pMag) used by the Edge-Based matching algorithm. Owns those raw buffers, so custom copy/move members are provided to manage them explicitly.
