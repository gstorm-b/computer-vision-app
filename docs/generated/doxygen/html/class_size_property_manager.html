Detailed Description

Compound property manager for physical or pixel sizes, exposing Width, Height (and Depth) as individual QtDoubleProperty sub-properties depending on the active Mode. Two display modes:

  • WH — Width, Height (2-D, e.g. image dimensions, pick-box)
  • WHD — Width, Height, Depth (3-D, e.g. bounding box)

Same factory-registration requirement as PositionPropertyManager: register subDoubleManager() with the browser's double editor factory.
