Detailed Description

Forward declarations of runtime runner types, referenced here only via QPointer/raw pointer so this header does not need to include the full runtime runner headers.

Runtime layer: device command/result value types and the queue/runner machinery that dispatches commands to per-device worker threads.

Runtime layer: per-device thread controllers that own and drive a device on its own worker QThread.

TaskRunner implementation: manages one QThread per registered device plus the task's own runtime coordinator thread, and drives the Idle -> Commission -> Runtime phase transitions.

Runtime device-thread management: TaskRunner and the per-device IDeviceRunner implementations that drive commissioning and runtime execution off the GUI thread.

Runner for the VisionOutput device family: thread lifecycle, signal wiring, and per-device runners (see VisionOutputRunner).
