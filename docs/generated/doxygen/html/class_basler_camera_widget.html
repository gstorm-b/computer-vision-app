Detailed Description

Device widget for a Basler GigE camera: exposes device/camera parameters through a QtPropertyBrowser, drives connect/trigger/save actions via CameraRunner, and hosts the board-calibration workflow (board setup, threshold tuning, corner detection, and calibration apply) for this camera.

vc::runtime::CameraRunner * runner,
ads::CDockWidget * dock = nullptr,
QWidget * parent = nullptr )
explicit

Runner is owned by TaskRunner (not by this widget). It must outlive this widget — TaskRunner guarantees this as long as the device stays assigned to the task. Pass nullptr only if the caller explicitly disables thread-routed access (rare; status lamp will stay disabled).

Parameters
dvthe Basler camera device this widget will control (expected to be castable to vc::device::BaslerGigECamera)
runnerthread-routed access point to the camera; nullptr disables control
dockoptional dock widget whose title is kept in sync with the device name
