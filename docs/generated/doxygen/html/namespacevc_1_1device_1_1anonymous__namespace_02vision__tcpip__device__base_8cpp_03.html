Lazily loaded, shared Nachi MZ04D simplified mesh-collision profile (voxel meshes), resolved via the deployed path then the source-tree fallback. The profile is fixed for the preset, so it is loaded once (function-local static) and reused; logs and returns nullptr if the file cannot be found or parsed.
