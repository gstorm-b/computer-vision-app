Detailed Description

Abstract base for per-algorithm runtime/learn parameters.

Each algorithm family (EdgeBased, Correlation, …) provides exactly one concrete subclass. The interface is kept Qt-free so the core matching library has no UI dependency. Property-browser integration lives entirely in MatchConfigPropertyAdapter.
