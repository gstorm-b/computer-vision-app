Detailed Description

Port (dependency-inversion boundary) that lets the pure-vision ImageMatcher ask "can the robot actually pick this object?" without depending on the robot kinematics / calibration / device layers. The concrete adapter (vc::model::RobotKinematicPickingChecker) lives in a higher layer.
