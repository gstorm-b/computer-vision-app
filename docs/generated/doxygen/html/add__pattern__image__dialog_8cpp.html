cv::Mat QPixmapToCvMat ( const QPixmap & pixmap)
inline

Converts a QPixmap to an OpenCV matrix, choosing the conversion by the pixmap's QImage format: Grayscale8 maps to a 1-channel CV_8UC1 clone, RGB888 converts RGB to BGR (CV_8UC3), RGBA8888 converts RGBA to BGRA (CV_8UC4), and any other format is first converted to RGBA8888 before the same RGBA-to-BGRA conversion.

Parameters
pixmapthe source pixmap
Returns
the converted image, or an empty cv::Mat if pixmap's QImage is null
