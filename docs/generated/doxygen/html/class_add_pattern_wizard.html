Detailed Description

5-step modal dialog reimplementation of PatternWizard.jsx: Image (capture from camera or open file + name + number), Crop (drag rect on canvas, or "use original frame"), Pick Point (click canvas to set pick X/Y), Picking Box (symmetric jaw pair — size + distance + angle), and Finish (preview + summary). All design tokens (colors, fonts, spacings) come from pattern_theme.h, which mirrors ui_scratch/design_handoff_full_project/README.md.

Note
Emits requestCameraImage() when the user picks "Capture from Camera" on Step 1; the host must capture a frame and feed it back via setCameraImage().
Result accessors (patternName(), patternNumber(), patternImage(), pickX()/Y(), pickBoxW()/H()/Dist()/Angle()) are only meaningful after exec() returns Accepted.

void AddPatternWizard::onImageSizeChanged ( int imageW,
int imageH )
private

Resizes all geometry spin boxes so they can mirror the canvas for the currently-loaded image, and clamps the default crop/pick to fit.

Parameters
imageWloaded image width, in pixels
imageHloaded image height, in pixels
Note
Called from setCameraImage() / setLoadedImage().

Widens the crop/pick/box spin-box ranges to span the newly-(re)loaded image (in image pixels), then clamps or re-centers the current crop rect and pick point so both stay inside the new image bounds, pushing the clamped values back into their spin boxes. All range/value changes are signal-blocked to avoid re-triggering onCropChanged() etc. No-op if either dimension is non-positive.
