Detailed Description

Resizable, movable, axis-aligned rectangular region-of-interest item for a QGraphicsScene: renders a dashed bounding box with an optional center cross-hair, shows four corner resize handles when selected, and keeps its position/size clamped inside its parent item's bounding rect.
