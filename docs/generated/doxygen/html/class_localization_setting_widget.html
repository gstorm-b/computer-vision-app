Detailed Description

Task settings widget for a localization task: binds the vision-output and PLC comm devices, the camera-number map, per-camera ROI workspaces, and the PLC signal-tag map to the underlying TaskLocalization's TaskLocalizeConfig, keeping the UI and the task's config in sync in both directions.
