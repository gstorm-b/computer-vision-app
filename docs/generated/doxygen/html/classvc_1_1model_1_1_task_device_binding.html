◆ kMinCameraNumber

int vc::model::TaskDeviceBinding::kMinCameraNumber = 1
staticconstexpr

Lowest allowed TaskDeviceRole::CameraNumber slot.

Camera bindings use 1..16 numbers — the task enforces the same bound at runtime via TaskLocalization::kLimitNumCamera. Device ids are short (numeric or short tokens); cap the length to reject malformed/hostile input. Kept local to avoid a dependency on TaskLocalization here.
