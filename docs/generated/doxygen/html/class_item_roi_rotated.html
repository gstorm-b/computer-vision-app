Detailed Description

Resizable, movable, and rotatable rectangular region-of-interest item for a QGraphicsScene: renders a dashed bounding box, four corner resize handles, and a dedicated rotation handle above the top edge when selected, and keeps its position and rotation constrained to stay inside its parent item's bounding rect.
