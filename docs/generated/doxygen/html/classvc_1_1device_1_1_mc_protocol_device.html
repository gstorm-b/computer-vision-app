Detailed Description

Mitsubishi MC-protocol PLC device: owns the transport (McMsgInterface) and frame codec (MCFrameAbstract), round-robins polling reads over the configured M/D device ranges, and serves ad-hoc digital/word writes via IPlcTagProvider/IPlcIoWriter.

void vc::device::McProtocolDevice::polling_query ( )
private

Drives one polling step: handles a pending response timeout via retry_request_handle(), otherwise pops the next ad-hoc request or advances the round-robin polling queue (and, on completing a full pass, emits pollingUpdate() and queues the comm-active toggle) before dispatching it with request_handle().

Drives one step of the polling state machine: if a response is still outstanding, checks for timeout and retries; otherwise pops the next ad-hoc request (if any) or the next scheduled polling request round-robin, updates m_data_update_state accordingly (emitting pollingUpdate() and queuing the heartbeat write when a full round completes), and dispatches it via request_handle().

Note
Locks m_mutex only while draining m_request_queue.
