Detailed Description

Abstract base for a configurable, stateful vision task: owns a set of assigned device ids, a per-task TaskRunner for commission/runtime thread management, and JSON (de)serialization of its identity and ITaskConfig. Concrete subclasses supply taskType(), isValid(), and device-limit checks.
