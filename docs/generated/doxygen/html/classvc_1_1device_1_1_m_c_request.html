Detailed Description

Concrete IRequest for the Mitsubishi MC protocol: describes a single bit or word read/write against a PLC device (device-type letter + start address + amount) and can encode the write payload into m_value.

QString head_device,

Builds a request from a textual PLC device address, e.g. "D100": the first character is the device-type letter, the remainder is parsed as the start address. Marks the request invalid (isValid() == false) if head_device is empty, the address fails to parse, or amount is not in (0, 64].

Parameters
head_devicedevice-type letter followed by the start address, e.g. "D100"
