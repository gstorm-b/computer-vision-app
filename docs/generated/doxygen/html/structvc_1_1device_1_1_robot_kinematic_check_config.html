Detailed Description

Optional reachability/singularity gate: when enabled, the vision output device runs inverse kinematics on each outgoing pick pose (built from x,y,z,r via the top-down pick convention, at the configured TCP) using the selected robot preset, and flags poses that are out of reach / out of joint limits / singular. When collisionCheckEnabled is also set, each reachable solution is additionally run through the Coal mesh self-collision check. Plain value type (no RobotKinematics dependency) so the config header stays light; the device builds the solver from these fields. Custom presets are not authored here (preset selection only, by name; the only built-in preset is "Nachi MZ04D").
