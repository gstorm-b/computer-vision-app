Detailed Description

A single clickable device entry (icon + name + short type label + connect-status dot) in a device navigation list. Style properties ("deviceType", "navActive") and the indicator dot's "lampState" drive QSS; setDevice() keeps it in sync with an vc::device::IDevice snapshot.
