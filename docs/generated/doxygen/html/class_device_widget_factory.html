Detailed Description

Factory that maps a device (by its concrete device type/subtype) to the matching device-specific control widget (e.g. Basler camera, Mitsubishi MC PLC, vision output).

QWidget * DeviceWidgetFactory::createDeviceWidget ( const std::shared_ptr< vc::device::IDevice > & device,
vc::runtime::IDeviceRunner * runner,
ads::CDockWidget * dock = nullptr,
QWidget * parent = nullptr )
static

Creates and returns the control widget appropriate for device's runtime type/subtype, wiring it to runner and, if given, hosting it inside dock.

Parameters
devicethe device to create a widget for; dispatch is based on its deviceType() and, where applicable, its subtype (camera type, PLC type, vision output type)
runnerthe device runner to bind to the widget, cast to the subtype-specific runner interface expected by the created widget
dockoptional dock widget host passed through to the created widget
parentoptional parent widget passed through to the created widget
Returns
a newly allocated widget owned by the caller, or nullptr if device is null or its type/subtype is not supported

Dispatches on device->deviceType() (and the relevant subtype enum) to construct the matching device widget; logs via LOG_DEV_ERR and returns nullptr for a null device or any unsupported type/subtype combination.
