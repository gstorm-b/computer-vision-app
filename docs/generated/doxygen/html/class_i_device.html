Detailed Description

Abstract base for every device family (camera/PLC/vision-output/robot): owns the device's id/name/task-assignment state, connection status, abstract IDeviceCfg pointer, and JSON (de)serialization; concrete subclasses implement connect/disconnect/request handling.
