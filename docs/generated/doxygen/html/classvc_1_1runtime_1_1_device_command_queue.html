Detailed Description

FIFO queue of pending DeviceCommand entries for a single device runner, applying a DeviceCommandQueuePolicy to decide whether/how to accept a new command while busy.

DeviceCommandEnqueueDecision vc::runtime::DeviceCommandQueue::enqueue ( const DeviceCommand & command,
DeviceCommandQueuePolicy policy,
bool busy )
inline

Decides how to handle command given whether the runner is currently busy, per policy. When not busy, the command is accepted to run immediately (nothing is queued). When busy, applies RejectWhenBusy/QueueWhenBusy/ReplacePendingSameKind, rejecting with DeviceCommandResultCode::Busy or QueueFull as appropriate.

Parameters
commandcommand being submitted
policyhow to handle the command if the runner is busy
busywhether the runner is currently executing another command
Returns
the enqueue outcome; check accepted/shouldRunNow, or rejection on failure
