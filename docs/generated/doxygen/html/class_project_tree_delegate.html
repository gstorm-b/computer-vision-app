Detailed Description

Item delegate that paints the default row content shrunk to leave room on the right, then draws a rounded, translucent-filled chip badge sourced from TreeItemRole::ChipText / TreeItemRole::ChipColor over that space; rows with no chip text fall back to plain QStyledItemDelegate painting.
