Detailed Description

Abstract base for the PLC family. Concrete vendors (McProtocolDevice for Mitsubishi MC, future OmronFinsDevice, SiemensS7Device, …) inherit from this base. The base only carries the family-level dispatch (plcType()) and the family JSON header; vendor-specific surface lives entirely on the concrete subclass.
