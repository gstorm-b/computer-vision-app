Detailed Description

Generic posture/branch descriptor for serial arms. The shoulder/elbow/wrist branch values are conventionally -1 or +1; vendor-specific branches are kept separately. Posture names (lefty/righty, above/below, flip/non-flip) are NOT hard-coded here; they live in preset/posture metadata and are mapped by a PostureResolver (Phase 4).
