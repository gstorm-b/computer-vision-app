Detailed Description

Composite widget presenting a VisionCanvas with a toolbar of view/overlay controls (fit-to-view button and an overlay-visibility menu with per-element toggles); wraps the canvas's image/overlay/selection API and forwards its selection signal.

◆ VisionResultViewerWidget()

VisionResultViewerWidget::VisionResultViewerWidget ( QWidget * parent = nullptr)
explicit

Builds the toolbar (fit button and overlay-visibility menu with one toggle action per VisionOverlayVisibility flag) and the read-only, pan-mode VisionCanvas, wires the fit button to VisionCanvas::fitImageToView, forwards the canvas's selection signal, and connects every overlay toggle to push visibilityFromActions() to the canvas whenever it changes.
