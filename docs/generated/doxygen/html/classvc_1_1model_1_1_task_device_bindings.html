Detailed Description

Ordered collection of a task's TaskDeviceBinding entries, with role-keyed convenience accessors for the single-valued roles (PrimaryPlc, VisionOutput) and the multi-valued CameraNumber role.

◆ fromJson()

bool vc::model::TaskDeviceBindings::fromJson ( const QJsonValue & value)
inline

Replaces all bindings by parsing value as a JSON array of binding objects. A missing/ null value clears the bindings and succeeds (treated as "no bindings"); a non-array value fails outright. Individual array entries that fail TaskDeviceBinding::fromJson() or carry an empty device id are dropped rather than aborting the whole parse.

Returns
false if value is present but not a JSON array, or if any entry failed to parse
