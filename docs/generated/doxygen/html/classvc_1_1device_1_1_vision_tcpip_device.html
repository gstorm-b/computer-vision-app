Detailed Description

TCP/IP server transport of the vision-output family: listens on two ports (main + heartbeat), accepts at most one client per port (pending duplicates are rejected), and delegates all protocol handling to VisionTcpipDeviceBase. The software remains the heartbeat master: it sends "connection_check." and expects "ack,{count}.". On lost connection the device drops the current client sockets but keeps the listeners open for the next reconnect.
