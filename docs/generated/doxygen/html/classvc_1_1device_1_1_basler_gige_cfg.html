Detailed Description

Basler GigE camera configuration: exposure/gain/frame-rate/backlight parameters plus camera identity (model/serial/IP), exposed as Q_GADGET properties for the property-browser UI (each G_PROPERTY_* macro below declares a property with generated getter/setter backed by the matching m_* field declared further down).
