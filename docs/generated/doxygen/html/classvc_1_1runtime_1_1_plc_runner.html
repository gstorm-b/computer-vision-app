Detailed Description

Family-level runner for the PLC device family; holds a PlcDevice* (the abstract base) so the runner stays sub-type-agnostic. Vendor-specific consumers reach the concrete device via qobject_cast<McProtocolDevice *>(runner->typedDevice()) and connect to the device's vendor signals directly (cross-thread queued). Mirrors CameraRunner / VisionOutputRunner: one flat runner per family, no per-vendor subclass.

Note
Commission mode: requestConnect() / requestDisconnect() from the GUI thread are queued to the PLC thread; connection status comes back via connectStatusChanged().
Runtime mode: the concrete PLC device runs its own polling loop on its thread; the task runtime thread listens to pollingUpdate() forwarded here.
