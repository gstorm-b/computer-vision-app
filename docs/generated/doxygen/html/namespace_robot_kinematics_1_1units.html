Detailed Description

Unit-conversion helpers between the library's SI internals (meters, radians) and the millimeter/degree units commonly used at API boundaries.

Unit-conversion helpers used throughout RobotKinematics to move between the library's canonical internal units (meters, radians) and the millimeter/degree units common in authoring/UI-facing data.
