Detailed Description

Circular status lamp widget: paints a filled, outlined circle centered in the widget, switching between an "enabled" and "disabled" fill color.

CLamp::CLamp ( QWidget * parent = nullptr)
explicit

Constructs the lamp with default state (disabled), gray/green colors, and a 1px outline; the drawn size auto-fits the widget until setLampMaxSize() is called.

Initializes default state: disabled, 1px outline, green enabled / gray disabled fill colors, and no fixed max size (auto-sizes to the widget).
