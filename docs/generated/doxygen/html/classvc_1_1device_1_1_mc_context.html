Detailed Description

Abstract base context for an MC-protocol PLC connection: holds the frame-independent addressing/refresh settings (M/D device ranges, poll interval) exposed to the UI via Q_PROPERTY, plus the message-interface config and device map shared by every concrete frame type (see Context_Mc3E for the 3E-frame specialization).
