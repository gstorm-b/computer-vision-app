bool RobotKinematics::anonymous_namespace{PostureResolver.cpp}::applyLabel ( const PostureMetadata & metadata,
const std::map< std::string, std::string > & labels,
const std::string & axis,
std::optional< int > & target )

Resolves one posture axis (e.g. "shoulder") to a branch sign by matching a caller-supplied label against the axis's configured negative/positive label pair.

Parameters
metadataposture metadata holding the configured label pairs per axis
labelscaller-supplied axis-name -> label-string map
axisname of the axis to resolve (e.g. "shoulder", "elbow", "wrist")
targetset to -1 or +1 when a match is found; left unmodified if axis is absent from labels
Returns
true if axis is absent from labels (nothing to resolve) or the requested label matched the configured negative/positive label; false if axis has no configured labels in metadata, or the requested label matches neither
