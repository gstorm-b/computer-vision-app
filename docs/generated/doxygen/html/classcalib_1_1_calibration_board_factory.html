Detailed Description

Centralised allocator for CalibrationBoard subclasses. Returns base-class std::unique_ptr<CalibrationBoard> so callers can stay board-agnostic. When type-specific accessors are needed (e.g. FanucIRvisionBoard::targetIndices), construct the subclass directly instead of going through the factory.
