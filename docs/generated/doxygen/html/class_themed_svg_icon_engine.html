Detailed Description

QIconEngine that resolves an SVG icon path through ThemeManager (so the icon follows the active light/dark theme/style) and caches rendered pixmaps in QPixmapCache keyed by style, path, mode, state, and size to avoid re-rendering the SVG each time.
