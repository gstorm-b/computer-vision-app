Detailed Description

Shared gadget meta-property helpers. Property-browser widgets dispatch edits through the Q_PROPERTY system of a Q_GADGET config; these helpers centralize the "indexOfProperty → read/write OnGadget" pattern and the "<prop>_name" Q_CLASSINFO display-name lookup emitted by the macros above, so each widget no longer re-implements it.
