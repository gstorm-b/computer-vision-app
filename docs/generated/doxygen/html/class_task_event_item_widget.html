Detailed Description

Visual row inside TaskEventLogWidget for a single TaskEvent.

Layout (left to right): [3 px severity bar] | [hh:mm:ss] | [LEVEL] | [[SOURCE]] | [message ...]

Styling is owned entirely by dark.qss / light.qss via: TaskEventItemWidget[severity="info"|"warning"|"error"|"success"] TaskEventItemWidget[...] QFrame[eventPart="bar"] TaskEventItemWidget[...] QLabel[eventPart="level"] QLabel[eventPart="time"|"message"|"source"]
