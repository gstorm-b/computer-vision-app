Detailed Description

Operator-facing task event log (read-only).

Designed for operator dashboards: shows discrete task events (ready, cycle start, fault, recovery ...) as a timestamped, severity-coded list. NOT a replacement for the global SystemLog – scope is the active task only.

Usage: TaskEvent ev; ev.level = TaskEventLevel::Error; ev.message = "Camera grab timeout - fault code 102."; ev.source = "Camera"; m_eventLog->appendEvent(ev);
