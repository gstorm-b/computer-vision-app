Detailed Description

Fanuc iRVision-style dot grid calibration board (concrete CalibrationBoard). Pattern: R x C grid of dots with 4 visual roles:

  • Normal dots : small solid black dots filling the grid
  • Target dots : 8 ring dots (4 corners + 4 edge midpoints), white inner
  • Centre dot : 1 larger ring dot at the grid centre, white inner
  • Coord dots : 3 larger solid dots near centre encoding +X (two dots right of centre) and +Y (one dot above centre)
    Note
    rows and cols MUST be odd; rows >= 5 and cols >= 7.

Detects the dot grid in image: binarizes, extracts near-circular blobs, identifies the 4 orientation markers (centre + 3 coord dots) by geometry, then projects the expected grid and matches each blob to its nearest cell.

Parameters
imageinput image (colour or grayscale)
imagePointsoutput; on success, one detected point per grid cell in row-major order
cornerImagePointsoptional output; the 4 corner dot positions (TL, TR, BR, BL) when non-null
debugOverlayoptional output; a BGR visualisation of the detected markers/grid/corners when non-null
Returns
true if the full grid (all totalDots() cells) was matched; false otherwise (imagePoints left empty)

Detects the dot grid in image: binarizes it (via binarize()), extracts near-circular blobs from contours (circularity + bounding-box squareness filters, plus a median-area outlier cap), takes the 4 largest surviving blobs as the orientation markers and resolves their roles via identifyOrientationMarkers4(), then projects the expected grid from those markers and greedily assigns each remaining blob to its nearest expected cell (within maxAcceptDist).
