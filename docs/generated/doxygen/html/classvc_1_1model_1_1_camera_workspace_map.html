Rebuilds all workspaces (ROI + flags only) from a JSON array produced by toJson(); clears any existing entries first. Reference images are not restored by this call.

Parameters
valueexpected to be a JSON array, or null/undefined for "no workspaces"
Returns
true on success; false if value is neither null/undefined nor an array. Array entries with an empty "cameraId" are silently skipped.
