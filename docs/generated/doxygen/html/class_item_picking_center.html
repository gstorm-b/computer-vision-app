Detailed Description

Selectable/movable QGraphicsItem marking a picking position: draws an X/Y axis cross with arrowheads at the item's center plus, optionally, a move handle (center dot) and a rotate handle (offset at 45°) that let the user drag-move and drag-rotate the item interactively.
